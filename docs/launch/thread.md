# Rowsetta launch thread

1. Rowsetta helps label a local CSV and export the learned rule as SQL, dbt,
   Python or JSON. The data stays on your machine.
2. The audit shows labels worth checking. A held-out sample measures accuracy
   and coverage; neither guarantees performance on future data.
3. The current benchmark results are smoke runs. The full comparison with
   direct tree baselines is still outstanding.
