# Security policy

This repository is under development and has no supported release yet.
Never include credentials, private datasets or exploit details in a public issue.

WAIT: configure private vulnerability reporting and a security
contact when a remote exists. Public launch is blocked until a private reporting
channel is available. No contact address or response-time promise is assumed.

Development checks use local data and require no model token. Secrets belong
in the local environment. `.env.example` lists configuration without credentials.
